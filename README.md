# 📊 Sales Performance Analysis Dashboard | Power BI

## 📌 Project Overview
This project focuses on analyzing sales performance using Microsoft Power BI. The dashboard provides insights into sales, orders, cost, and profit through interactive visualizations and KPI indicators.

The objective is to help understand sales trends, product performance, and business profitability.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Visualization
- Data Analysis

## 📈 Key Performance Indicators (KPIs)

| KPI | Result |
|---|---:|
| Total Sales | $24.9M |
| Total Orders | 56K |
| Total Cost | $14.46M |
| Total Profit | $10.46M |

## 📊 Dashboard Features

- Sales Analysis by Month
- Sales Analysis by Year
- Sales by Product Subcategory
- Top 5 Profitable Products
- Continent-wise Filtering
- Year-wise Filtering
- Product Category Filtering
- Interactive Reset Button

## 🔍 Key Insights

- Total sales reached $24.9M.
- Total profit was $10.46M.
- Total orders reached 56K.
- 2016 recorded the highest annual sales among the displayed years.
- Road Bikes generated the highest profit among the top five products shown.
- Monthly sales trends showed noticeable variations throughout the year.

## 🎯 Project Objective

To develop an interactive business intelligence dashboard that transforms sales data into meaningful insights and supports data-driven decision-making.
